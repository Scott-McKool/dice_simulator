
A simple HTML tool for generating graphs that describe dice rolls.

The graph is the frequencies of each possible sum after rolling X N-sided dice, with the option to keep the K highest or lowest rolls.

This tool was primarily meant for describing the probabilities of different dice rolls in table-top games like D&D.

Here is a link to test it out: https://scott-mckool.github.io/dice_simulator/
